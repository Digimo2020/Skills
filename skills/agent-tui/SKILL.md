# Agent TUI Automation

Enables headless or automated execution of terminal-based user interfaces.

## Capabilities
- Inject terminal keystrokes, navigation commands, and escape sequences.
- Capture screen buffers and inspect cursor positions.
- Verify that terminal redraws, colors, and layouts match expectations across varying viewport dimensions.
