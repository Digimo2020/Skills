# Changelog Generator

Compiles clean, human-readable release changelogs from commits and pull request metadata.

## Format
- Group by Conventional Commit categories (Features, Bug Fixes, Documentation, Breaking Changes).
- Link PRs and contributor handles.
- Highlight breaking changes and migration steps prominently.
